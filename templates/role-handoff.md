# 角色交接单

交付角色以 `agent_name` 作为用户可见身份；不得填写 runtime ID、UUID 或哈希。

当前交接只维护本轮有效信息；过期交接在有效内容收敛后删除，不将完整历史正文反复追加到本文件。

使用者是后续开发 agent。仅保留任务恢复需要的状态、有效约束及原因、代码/验证入口和未解决事项。里程碑完成时，将已结束的等待/交接步骤替换为当前基线与后续任务入口，不沿用旧审批待办；不据此启动下一里程碑。

## 需求确认闭环

- 本次采用的理解与边界：引用现有确认条目，不复制整份需求；
- 用户确认来源与覆盖范围：明确答复/原始约束所在条目及时间；
- 尚未确认的关键假设及被阻塞的工作：没有则写无；
- 本轮撤销的旧理解及受影响产物：无纠正时省略。
- 上游结论的保留/调整/移除及确认来源：只链接有变化的条目，无变化时注明沿用。

## UI 交付与接收（仅设计、前端及 UI 验证适用）

填写本角色有关的内容，其余省略；详细规则与文案留在设计真源，本栏只提供可接续的入口。

- 交付用途、当前设计 commit/快照、获批用途/范围及规格入口：正式设计接收按设计交付协议检查。
- 原型启动、页面/区域/状态、文案源、样式和资源定位：引用规格中的对应条目，不重复正文。
- 接收检查及本角色结果：设计记录产物一致性；前端记录源到工程的转换位置与运行页面自检；QA 记录覆盖/报告入口。
